# منصة التحليل العددي (Numerical Analysis Platform)

---

## 1. طريقة التشغيل (How to Run)

### متطلبات التشغيل:
- لغة Python 3.10 أو أحدث.
- تثبيت الحزم المطلوبة عبر الأمر:
```bash
pip install -r requirements.txt
```

### تشغيل التطبيق:
من داخل مجلد `project`، شغّل الأمر:
```bash
py main.py
```
أو:
```bash
python main.py
```

### التشغيل المباشر للملف التنفيذي (.exe):
يمكن تشغيل المنصة مباشرة دون الحاجة لتثبيت بايثون عبر النقر المزدوج على:
`NumericalAnalysis.exe`

### تشغيل الفحوصات والاختبارات الآلية:
```bash
# فحص جميع الخوارزميات الـ 12 مع الحالات الحدية:
py test_all_methods.py

# فحص دورة حياة وتدفق الواجهات الرسومية:
py test_gui_flow.py
```

## 3. جدول مطابقة الماتلاب بالبايثون (MATLAB to Python Mapping)

تمت مطابقة الطرق البرمجية الواردة في ملفات المقرر الأصلية سطراً بسطر بين كود الماتلاب وكود البايثون المقابل:

| الطريقة العددية | ملف الماتلاب الأصلي | ملف البايثون المقابل | الأسطر في الماتلاب | الكود المقابل في البايثون |
| :--- | :--- | :--- | :--- | :--- |
| **حذف جاوس والتعويض العكسي** | `gauss.m` | `methods/gauss.py` | `n = length(A);` | `n = len(A)` |
| | | | `L = -A(i, k) / A(k, k);` | `factor = M[i][k] / pivot` |
| | | | `A(i, :) = A(i, :) + L * A(k, :);`<br/>`B(i) = B(i) + L * B(k);` | `M[i][j] -= factor * M[k][j]`<br/>`V[i] -= factor * V[k]` |
| | | | `X(n) = B(n) / A(n, n);`<br/>`X(i) = (B(i) - A(i, i+1:n)*X(i+1:n)) / A(i, i);` | `X[i] = (V[i] - sum(M[i][j] * X[j])) / M[i][i]` |
| **طريقة جاكوبي التكرارية** | `jacobi.m` | `methods/jacobi.py` | `abs(A(i,i)) > sum(abs(A(i,:))) - abs(A(i,i))` | `abs(A[i][i]) > sum(abs(A[i][j]) for j != i)` (فحص السيادة القطرية) |
| | | | `x_new(i) = (B(i) - sum_{j~=i} A(i,j)*x_old(j)) / A(i,i);` | `X_new[i] = (B[i] - s) / A[i][i]` |
| | | | `norm(x_new - x_old) <= e` | `error = max(abs(X_new[i] - X_old[i])) <= tol` |
| **استيفاء كثيرات حدود لاجرانج** | `lagrang.m` | `methods/lagrange.py` | `n = length(s); syms x; P = 0;` | `n = len(x_points); x = sympy.Symbol('x'); P = 0` |
| | | | `L = L * (x - s(j)) / (s(i) - s(j));` | `L_i *= (x_sym - xj) / (xi - xj)` |
| | | | `P = P + L * f(i);` | `P_sym += L_i * yi` |
| | | | `disp(simplify(P));` | `sympy.simplify(P_sym)` وتقدير $P(x_{\text{eval}})$ |

> **ملاحظة:** الطرق الأخرى بالمقرر (التنصيف، الموضع الخاطئ، القاطع، نيوتن رافسون، النقطة الثابتة، قاعدة كرامر، معكوس المصفوفة، شبه المنحرف المركبة، والتفاضل العددي) بُنيت مباشرة بالصيغ الرياضية المعتمدة للمقرر وفق نفس المنهجية والدقة.
