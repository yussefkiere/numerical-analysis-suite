# مرجع أكواد الماتلاب المعتمدة (MATLAB Reference)

يحتوي هذا المجلد على ملفات الماتلاب الأصلية للمقرر، والمخصصة للمقارنة الشفهية أثناء مناقشة المشروع.

---

### ملفات الماتلاب الأصلية:
1. `gauss.m`: كود حذف جاوس والتعويض العكسي (Gaussian Elimination).
2. `jacobi.m`: كود طريقة جاكوبي التكرارية مع فحص السيادة القطرية (Jacobi Iteration).
3. `lagrang.m`: كود كثيرات حدود لاجرانج والاستيفاء الرمزي والعددي (Lagrange Interpolation).

> **ملاحظة أكاديمية للمناقشة:**
> - الطرق الثلاث أعلاه (`gauss.m`, `jacobi.m`, `lagrang.m`) تمت مطابقة خوارزمياتها في بايثون بدقة سطراً بسطر مع كود الماتلاب، مع توثيق جدول مطابقة الأسطر في ترويسة ملفات بايثون المقابلة (`methods/gauss.py`, `methods/jacobi.py`, `methods/lagrange.py`).
> - باقي الطرق التسع في المقرر كُتبت مباشرة بلغة Python وفق الصياغة الرياضية المعيارية المعتمدة في المراجع، دون اختلاق كود ماتلاب غير موجود في المصادر.
