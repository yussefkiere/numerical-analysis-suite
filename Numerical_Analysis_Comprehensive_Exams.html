1.1) إذا طُبقت طريقة التنصيف لحصر جذر في الفترة [1, 5]، فإن طول الفترة بعد n = 4 تكرارات يساوي:

💡 الشرح والحل النموذجي (درجتان): الإجابة الصحيحة: (ب)
القانون العام لطول الفترة في التكرار n هو:
L_n = \frac{b - a}{2^n} = \frac{5 - 1}{2^4} = \frac{4}{16} = 0.25
1.2) رتبة تقارب طريقة نيوتن-رافسون (Order of Convergence) عند البحث عن جذر بسيط للمعادلة f(x) = 0 هي:
أ خطية (Linear) بمعدل 1
ب تربيعية (Quadratic) من الرتبة 2
ج فوق خطية برتبة 1.618
د تكعيبية من الرتبة 3
💡 الشرح والحل النموذجي (درجتان): الإجابة الصحيحة: (ب)
تتقارب طريقة نيوتن رافسون تربيعياً e_{k+1} \approx C \cdot e_k^2 بشرط أن يكون الجذر بسيطاً f'(r) \neq 0 وأن تكون نقطة البداية قريبة بالقدر الكافي من الجذر.
1.3) تنهار طريقة نيوتن-رافسون (تتعذر مواصلة الحل) تماماً عند التكرار x_k إذا كانت:
أ f(x_k) = 0
ب f'(x_k) = 0
ج f''(x_k) = 0
د x_k < 0
💡 الشرح والحل النموذجي (درجتان): الإجابة الصحيحة: (ب)
قانون نيوتن هو x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}، فإذا كانت المشتقة f'(x_k) = 0، يكون مماس المنحنى أفقياً وموازياً لمحور السينات، فيحدث خطأ القسمة على الصفر ويستحيل إيجاد نقطة التقاطع.
1.4) في طريقة حذف جاوس، معامل ضرب الصف k لإلغاء وتصفير العنصر a_{ik} في الصف i هو:
أ m_{ik} = a_{ik} / a_{kk}
ب m_{ik} = a_{kk} / a_{ik}
ج m_{ik} = a_{ik} \cdot a_{kk}
د m_{ik} = a_{ii} / a_{kk}
💡 الشرح والحل النموذجي (درجتان): الإجابة الصحيحة: (أ)
المعامل المعياري هو نسبة العنصر المراد تصفيره إلى العنصر المحوري في الصف الرئيسي: R_i \leftarrow R_i - \left(\frac{a_{ik}}{a_{kk}}\right) R_k.
1.5) شرط التقارب الكافي لطريقة النقطة الثابتة x_{k+1} = g(x_k) في فترة تحتوي الجذر هو:
أ |g'(x)| > 1
ب |g'(x)| < 1
ج g'(x) = 0 دائماً
د g(x) = 0
💡 الشرح والحل النموذجي (درجتان): الإجابة الصحيحة: (ب)
وفق نظرية النقطة الثابتة لـ باناخ (Contraction Mapping Theorem)، يشترط أن يكون ميل دالة التكرار محصوراً بحيث |g'(x)| \le k < 1 لضمان انكماش المسافة بين التكرارات نحو الجذر.

يمثل ميل المماس لمنحنى الدالة y = f(x) عند النقطة (x_0, f(x_0)) المشتقة الأولى للدالة m = f'(x_0). يمتد هذا المماس ليقطع محور السينات عند النقطة (x_1, 0) والتي تمثل التقريب الأفضل للجذر الحقيقي r.

2. خطوات الاشتقاق الجبري (6 درجات):

    y - f(x_0) = f'(x_0) \cdot (x - x_0) \quad \text{[درجتان]}
  • بما أن التقريب الجديد x_1 يقع عند تقاطع المماس مع محور السينات (y = 0)، نعوض y = 0 و x = x_1:
    0 - f(x_0) = f'(x_0) \cdot (x_1 - x_0) \quad \text{[درجتان]}
  • بقسمة الطرفين على f'(x_0) (بشرط f'(x_0) \neq 0):
    -\frac{f(x_0)}{f'(x_0)} = x_1 - x_0
  • بعزل x_1 في طرف مستقل والتعميم لكافة التكرارات k:
    x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)} \quad \text{[درجتان]}

2.1) طريقة استيفاء لاجرانج لعدد n + 1 من النقاط المعطاة تُنتج كثيرة حدود فريدة من الدرجة:
أ n + 1 دائماً

ج n - 1 فقط
د لا علاقة لدرجة الدالة بعدد النقاط
💡 التفسير:الإجابة: (ب)
تنص مبرهنة وحدانية كثيرات حدود الاستيفاء على أن n+1 نقطة متمايزة تحدد كثيرة حدود وحيدة درجتها \le n.
2.2) رتبة خطأ البتر التراكمي (Truncation Error Order) في قاعدة شبه المنحرف المركبة ذات الخطوة h هي:
أ O(h)
ب O(h^2)
ج O(h^3)
د O(h^4)
💡 التفسير:الإجابة: (ب)
صيغة خطأ شبه المنحرف المركب هي E = -\frac{b-a}{12} h^2 f''(\xi)، وبالتالي يتناسب الخطأ طرداً مع h^2 أي O(h^2).
2.3) في التفاضل العددي بصيغ تايلور، صيغة الفرق المركزي f'(x_0) \approx \frac{f(x_0+h) - f(x_0-h)}{2h} تمتاز عن صيغتي الفرق المتقدم والتراجعي بأنها:
أ لا تتطلب قسمة على h
ب أكثر دقة برتبة خطأ O(h^2) مقابل O(h)
ج تصلح للدوال غير المستمرة فقط
د تحسب المشتقة الثانية مباشرة

عند طرح متسلسلة تايلور المتقدمة من التراجعية، تختفي الحدود الفردية للخطأ، ويبقى أول حد للخطأ متناسباً مع h^2.
2.4) لكي تتقارب طريقة جاكوبي التكرارية لحل النظام AX = B من أي نقطة بداية، الشرط الكافي هو أن تكون مصفوفة المعاملات A:
أ مصفوفة متماثلة وموجبة فقط
ب مهيمنة قطرياً بشكل صارم (Strictly Diagonally Dominant)
ج مصفوفة مثلثية سفلية
د محددها مساوٍ تماماً لـ 1

الشرط هو |a_{ii}| > \sum_{j \neq i} |a_{ij}| لكل صف، مما يجعل نصف القطر الطيفي لمصفوفة التكرار أقل من 1.
2.5) في دوال الأساس اللاجرانجية L_i(x)، قيمة L_i(x_j) عند العقد المختلفة (i \neq j) تساوي دائماً:
أ 0 (صفر)
ب 1 (واحد)
ج y_i
د x_i - x_j

تحقق دوال لاجرانج خاصية دلتا كرونيكر: L_i(x_j) = 1 إذا كان i = j، وتساوي 0 إذا كان i \neq j لأن البسط يحتوي العامل (x - x_j) فينعدم.

1. [   ] طريقة القاطع (Secant Method) تتطلب نقطتي بداية x_0, x_1 ويشترط حتماً أن تكون الدالة مختلفة الإشارة عندهما f(x_0) \cdot f(x_1) < 0.

التصحيح: طريقة القاطع هي طريقة مفتوحة (Open Method) لا تشترط حصر الجذر باختلاف الإشارة، بل يمكن أن تكون f(x_0) و f(x_1) من نفس الإشارة. الطريقة التي تشترط اختلاف الإشارة دوماً هي طريقة الموضع الخاطئ (False Position) والتنصيف.
2. [   ] يمكن تطبيق قاعدة كرامر لحل أي نظام خطي AX = B حتى وإن كان محدد مصفوفة المعاملات مساوياً للصفر \det(A) = 0.

3. [   ] إذا فشل شرط الهيمنة القطرية لنظام معادلات خطية، يجوز تبديل مواقع المعادلات (صفوف المصفوفة) للوصول إلى الهيمنة القطرية قبل تشغيل طريقة جاكوبي.

def cramer_solver(A, B):
    det_A = np.linalg.det(A)
    if det_A == 0:
        print("النظام له عدد لا نهائي من الحلول")

        Ai = A            # هل هذا صحيح؟
        Ai[:, i] = B
        xi = np.linalg.det(Ai) * det_A
        X.append(xi)
    return X

إثبات 1: اشتقاق قانون طريقة القاطع (Secant Formula Derivation) إثبات
اشتق قانون طريقة القاطع انطلاقاً من معادلة الخط المستقيم (الوتر القاطع) المار بالنقطتين (x_{n-1}, f(x_{n-1})) و (x_n, f(x_n)).
خطوات الإثبات الرياضي الكامل:
  1. ميل الخط المستقيم القاطع المار بالنقطتين هو:
    m = \frac{f(x_n) - f(x_{n-1})}{x_n - x_{n-1}}
  2. معادلة المستقيم القاطع باستخدام النقطة (x_n, f(x_n)) والميل m:
    y - f(x_n) = m (x - x_n) = \frac{f(x_n) - f(x_{n-1})}{x_n - x_{n-1}} (x - x_n)
  3. التقريب الجديد x_{n+1} يقع عند تقاطع المستقيم مع محور السينات (y = 0):
    0 - f(x_n) = \frac{f(x_n) - f(x_{n-1})}{x_n - x_{n-1}} (x_{n+1} - x_n)
  4. بضرب الطرفين في مقلوب الميل:
    (x_{n+1} - x_n) = -f(x_n) \cdot \frac{x_n - x_{n-1}}{f(x_n) - f(x_{n-1})}
  5. بعزل x_{n+1}:
    x_{n+1} = x_n - f(x_n) \cdot \frac{x_n - x_{n-1}}{f(x_n) - f(x_{n-1})} \quad \blacksquare
إثبات 2: اشتقاق صيغة الفرق المركزي ورتبة خطأ O(h²) من متسلسلة تايلور إثبات
باستخدام مفكوك متسلسلة تايلور للدالة f(x) حول النقطة x_0 بالخطوتين +h و -h: اشتق صيغة الفرق المركزي للمشتقة الأولى f'(x_0) وأثبت رياضياً أن خطأ البتر هو من الرتبة الثانية O(h^2).
خطوات الإثبات الرياضي الكامل:
  1. مفكوك تايلور المتقدم عند x_0 + h:
    f(x_0 + h) = f(x_0) + h f'(x_0) + \frac{h^2}{2} f''(x_0) + \frac{h^3}{6} f'''(x_0) + O(h^4) \quad \text{--- (1)}
  2. مفكوك تايلور التراجعي عند x_0 - h:
    f(x_0 - h) = f(x_0) - h f'(x_0) + \frac{h^2}{2} f''(x_0) - \frac{h^3}{6} f'''(x_0) + O(h^4) \quad \text{--- (2)}
  3. بطرح المعادلة (2) من المعادلة (1):
    f(x_0 + h) - f(x_0 - h) = 2h f'(x_0) + \frac{2h^3}{6} f'''(x_0) + O(h^5)
    نلاحظ إلغاء الحدود المتضمنة f(x_0) و h^2 f''(x_0).
  4. بقسمة الطرفين على 2h:
    \frac{f(x_0 + h) - f(x_0 - h)}{2h} = f'(x_0) + \frac{h^2}{6} f'''(x_0) + O(h^4)
  5. بعزل المشتقة f'(x_0):
    f'(x_0) = \frac{f(x_0 + h) - f(x_0 - h)}{2h} - \frac{h^2}{6} f'''(\xi) = \frac{f(x_0 + h) - f(x_0 - h)}{2h} + O(h^2) \quad \blacksquare
    وهذا يثبت أن رتبة الخطأ هي O(h^2).

سؤال برمجي 1: كود طريقة جاكوبي المعتمد في المقرر (MATLAB Code) MATLAB
اكتب دالة MATLAB كاملة وموثقة باسم function x = my_jacobi(A, b, x0, tol, max_iter) تعكس الكود المرجعي المعتمد في المقرر، مع شرح كل سطر.
كود جاكوبي المرجعي في MATLAB:
function x = my_jacobi(A, b, x0, tol, max_iter)
    % A: مصفوفة المعاملات [n x n]
    % b: متجه الحدود المطلقة [n x 1]
    % x0: متجه البداية الأولي
    % tol: التسامح المسموح للخطأ (شرط التوقف)
    % max_iter: الحد الأقصى لعدد التكرارات
    
    n = length(b);
    x = x0;
    x_new = zeros(n, 1);
    
    for k = 1:max_iter
        for i = 1:n
            % حساب مجموع حاصل ضرب المعاملات في المتغيرات باستثناء القطر
            sum_val = 0;
            for j = 1:n
                if j ~= i
                    sum_val = sum_val + A(i, j) * x(j);
                end
            end
            % تحديث المتغير x_i وفق صيغة جاكوبي
            x_new(i) = (b(i) - sum_val) / A(i, i);
        end
        
        % فحص شرط التوقف بحساب المعيار الإقليدي للخطأ
        if norm(x_new - x, inf) < tol
            fprintf('تقاربت طريقة جاكوبي بنجاح في %d تكرار\n', k);
            x = x_new;
            return;
        end
        
        x = x_new; % تجهيز التكرار التالي
    end
    warning('وصلت الطريقة إلى الحد الأقصى للتكرارات دون تقارب تام');
end
