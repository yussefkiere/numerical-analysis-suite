# 📊 مكتبة خوارزميات التحليل العددي بلغة MATLAB (.m)
## مقرر التحليل العددي - النسخة الأكاديمية البرمجية المعتمدة

تم إعداد وتطوير هذه الحزمة لتضم **كافة خوارزميات التحليل العددي المقررة**، وبخاصة خوارزميات **المعادلات الخطية والغير خطية**، ومكتوبة بنقاء قياسي تام متوافق مع كافة إصدارات **MATLAB** و **GNU Octave**.

---

### 📁 هيكل ملفات المجلد ومحتواها:

| اسم الملف | اسم الطريقة | التصنيف | الوظيفة والمعادلة |
| :--- | :--- | :--- | :--- |
| **`bisection.m`** | طريقة التنصيف | معادلات غير خطية | حصر الجذر في فترة `[a, b]` وتنصيفها تكرارياً |
| **`false_position.m`** | طريقة الموضع الخاطئ | معادلات غير خطية | تقاطع وتر الدالة مع محور السينات (Regula Falsi) |
| **`secant.m`** | طريقة القاطع | معادلات غير خطية | طريقة مفتوحة بنقطتين دون الحاجة لاشتقاق الدالة |
| **`newton_raphson.m`** | طريقة نيوتن رافسون | معادلات غير خطية | أسرع الطرق تقارباً بالاعتماد على مماس المنحنى $f'(x)$ |
| **`fixed_point.m`** | طريقة النقطة الثابتة | معادلات غير خطية | صياغة $x = g(x)$ والتكرار بشرط $\|g'(x)\| < 1$ |
| **`gauss_elimination.m`** | طريقة حذف جاوس | أنظمة خطية | تحويل المصفوفة الموسعة لشكل مثلثي علوي مع التعويض العكسي |
| **`jacobi.m`** | طريقة جاكوبي التكرارية | أنظمة خطية | حل تكراري مع فحص شرط الهيمنة القطرية الصارمة |
| **`cramer_rule.m`** | قاعدة كرامر بالمحددات | أنظمة خطية | حل النظام بحساب نسب المحددات $x_i = \det(A_i)/\det(A)$ |
| **`matrix_inversion.m`** | طريقة معكوس المصفوفة | أنظمة خطية | حل النظام $X = A^{-1} B$ مع طباعة المصفوفة المعكوسة |
| **`lagrange_interpolation.m`** | استيفاء كثيرات حدود لاجرانج | استيفاء وتوفيق | تقدير قيمة الدالة بالاعتماد على دوال أساس لاجرانج $L_i(x)$ |
| **`trapezoidal_rule.m`** | قاعدة شبه المنحرف المركبة | تكامل عددي | حساب التكامل العددي بدقة شرائح $h$ وصيغة الخطأ |
| **`numerical_differentiation.m`** | صيغ التفاضل العددي | تفاضل عددي | المشتقات الأولى والثانية بصيغ الفروق (الأمامية، الخلفية، والمركزية) |
| **`run_all_algorithms.m`** | السكربت الشامل | فحص وتشغيل | يشغل جميع الخوارزميات الـ 12 بنقرة واحدة مع جداول نتائجها |

### 💻 كيفية الاستخدام في بيئة MATLAB:

#### 1. التشغيل المباشر السريع (Default Run):
كل ملف مصمم ليعمل كـ **Script** و **Function** في آن واحد:
- بمجرد فتح أي ملف مثل `bisection.m` أو `jacobi.m` في MATLAB والضغط على **Run (F5)**، سيقوم تلقائياً بتنفيذ المثال المعياري المعتمد بالمحاضرات مع طباعة جدول تكرارات أنيق في الـ Command Window.

#### 2. الاستدعاء كدالة داخل الأكواد (Function Call):
يمكنك استدعاء أي خوارزمية وتمرير دوالك ومصفوفاتك الخاصة كالتالي:

```matlab
% مثال: حل معادلة غير خطية بطريقة نيوتن رافسون
f  = @(x) x.^3 - x - 2;
df = @(x) 3*x.^2 - 1;
[root, table] = newton_raphson(f, df, 1.5, 1e-5, 20);

% مثال: حل نظام خطي بحذف جاوس
A = [2, 1, -1; 3, 5, 2; 4, -1, -2];
b = [-1; 2; 1];
[x, Aug] = gauss_elimination(A, b);

% مثال: حل نظام خطي بطريقة جاكوبي التكرارية
A = [8, 1, 1; 3, 5, -1; 1, -1, 5];
b = [26; 7; 7];
[x, table] = jacobi(A, b);
```

#### 3. تشغيل جميع الخوارزميات معاً:
افتح ملف **`run_all_algorithms.m`** واكتب في الـ Command Window:
```matlab
run_all_algorithms
```
سيقوم السكربت بتشغيل جميع الخوارزميات الـ 12 وطباعة كافة النتائج التفصيلية.
